# Sly Contest
## Description FR
Jeu de plateforme multijoueur auto-hébergé où l'objectif est de créer un niveau composé de plateformes et de pièges que l'adversaire doit compléter dans un laps de temps défini. Une fois la phase de construction du niveau achevée, les deux joueurs doivent parcourir le niveau créé par l'autre, puis accomplir leur propre niveau pour prouver sa faisabilité.

Plus de détails sur le [wiki](https://github.com/katsulon/Sly-Contest/wiki).

Lien du projet sur le portfolio imagerie de la HE-Arc [ici](https://he-arc.github.io/imagerie-portfolio/projects/2024_p2_sly_contest/).

## Description EN
Self-hosted multiplayer platformer where the goal is to create a platformer level full of traps that the enemy player has to complete in the alloted time. Once the construction phase time has run out, both players have to complete the level created by the other, before completing their own level in order to prove it's possible.

More details on the [wiki](https://github.com/katsulon/Sly-Contest/wiki) (FR only).
